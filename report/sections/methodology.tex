\section{Methodology}

\subsection{Datasets and feature extraction}
We use two chest X-ray datasets with distinct roles: the NIH Chest X-ray 10k subset for learning the sparse representation, and Open-I for evaluating the extracted concepts against radiology reports.

The NIH subset contains 10,000 images. We retain its provided split, using the 7,500 training images to fit the sparse autoencoder (SAE) and the 2,500 images in the test split as a validation set for early stopping and model selection. The SAE learns exclusively from image embeddings, without report text or disease labels.

Open-I provides chest X-ray images paired with radiology reports, allowing us to assess whether the concepts extracted from an image are supported by the corresponding clinical text. We use the frontal image from each record, excluding records with missing frontal images. For each image, we construct a reference report by concatenating the available \emph{Findings} and \emph{Impression} sections, which describe the radiological observations and their diagnostic interpretation. Records with combined reports under ten characters are discarded. This preprocessing yields 3,666 image--report pairs, forming the pool from which the semantic evaluation samples are drawn. Open-I images and reports are not used to train the SAE.

We use BiomedCLIP's frozen ViT-B/16 image encoder for images from both datasets to produce the visual embeddings used for SAE training and inference.


\subsection{Concept dictionary construction}
To assign interpretable names to the features learned by the SAE, we construct a dictionary of medical concepts. We start from Open-I's \emph{Problems} metadata, which contains medical terms associated with each record. After normalizing formatting and removing duplicates, we obtain 116 distinct candidate terms. We exclude 15 device, procedure, and technical terms, map broad terms to chest X-ray terminology (e.g., “opacity” to “lung opacity”), and merge any resulting duplicates. This yields 100 parent concepts covering anatomical structures and pathological findings.

We then query the Unified Medical Language System (UMLS)~\cite{bodenreider2004umls} for an exact match to each concept. For matched concepts, we retrieve a Concept Unique Identifier (CUI) and available English synonyms from SNOMED CT and MeSH, two medical terminology resources accessible through UMLS. This step links the vocabulary to standardized terminology while preserving alternative names for the same concept. We obtain a CUI for 90 concepts; the remaining ten retain their base term as a fallback.

To complement these terminology entries with radiology-style descriptions, we use Gemini 3.1 Flash-Lite to generate five short phrases per concept, providing the base term and available synonyms as input. The prompt requests descriptions of visible features consistent with the concept, including normal anatomy. We check that phrases are unique within each concept and contain 6–16 words and at most 140 characters.

Finally, we encode each dictionary entry independently using BiomedCLIP’s frozen PubMedBERT text encoder and L2-normalize its embedding, which lies in the same latent space as the image features. The resulting matrix, \(T\in\mathbb{R}^{998\times512}\), contains 498 base-term and synonym entries and 500 generated phrases, with each row linked to its parent concept.


\subsection{Sparse Autoencoder and concept assignment}
We train an SAE to represent each image embedding through a sparse combination of learned features. The input dimension is $d=512$ and the hidden dimension is $m=1,024$, giving an overcomplete factor of $m/d=2$. For an image embedding $x\in\mathbb{R}^{d}$, the encoder produces non-negative activations $z\in\mathbb{R}^{m}$, from which the decoder reconstructs the input:
\begin{equation}
z=\operatorname{ReLU}(W_e(x-b_d)+b_e),\qquad
\hat{x}=W_dz+b_d,
\end{equation}
Here, $W_e$ and $W_d$ are the encoder and decoder weights, and $b_e$ and $b_d$ are learned biases. Training combines reconstruction error with an $L_1$ penalty that encourages sparse activations:
\begin{equation}
\mathcal{L}=\frac{1}{512B}\sum_{i=1}^{B}\|x_i-\hat{x}_i\|_2^2
+\frac{\lambda}{B}\sum_{i=1}^{B}\|z_i\|_1,
\end{equation}
where $B=256$ is the batch size and $\lambda=5\times10^{-5}$ controls the sparsity penalty. We train with Adam and use validation loss for early stopping and model selection.

After SAE training, each decoder column represents a learned feature direction in the image embedding space. We assign a concept phrase to each feature by comparing its decoder column with the dictionary embeddings. This naming step does not affect the learned weights. We compute the similarities as
\begin{equation}
S=T\widetilde{W}_d\in\mathbb{R}^{998\times1024},
\end{equation}
where $\widetilde{W}_d$ contains the normalized decoder columns. Since the rows of $T$ also have unit length, $S_{pj}$ is the cosine similarity between phrase $p$ and feature $j$. Then, each feature receives the phrase with the highest similarity in its column of $S$. Features are matched independently, allowing multiple features to receive the same phrase label.

Once the learned features have been assigned phrase labels, we use the trained SAE to extract concepts from Open-I images. For each image, we feed its BiomedCLIP embedding into the SAE and select the active neurons whose cumulative activation exceeds 90\% of the total positive activation, starting with the largest values. Let $z_{(1)}\geq\cdots\geq z_{(M)}>0$ denote the $M$ positive activations in descending order. The number of selected features is
\begin{equation}
k^*=\min\left\{k\in\{1,\ldots,M\}:\frac{\sum_{j=1}^{k}z_{(j)}}{\sum_{j=1}^{M}z_{(j)}}>0.90\right\}.
\end{equation}
This allows the number of selected features to vary across images. We collect the labels of the first $k^*$ features and remove duplicate phrases to obtain the predicted concept set. No minimum cosine-similarity threshold is applied.


\subsection{Semantic evaluation and validation}
To assess whether the concepts extracted from each Open-I image are supported by its radiology report, we use a frozen MedGemma 1.5 4B~\cite{sellergren2026medgemma15} as an automated evaluator. For each predicted concept, the model receives its phrase label and the corresponding report, without the image. The prompt provides definitions and examples for three verdicts: \emph{Aligned} when the report explicitly supports the concept; \emph{Unaligned} when it explicitly negates or contradicts the concept; and \emph{Uncertain} when the concept is unmentioned, ambiguous, or tentative.

We map the verdict classes to single-token answers A, B, and C, rotating the class–letter mapping across three forward passes to reduce letter bias. In each pass, we apply softmax to letters' next-token scores and map the probabilities back to the classes. The class with the highest average probability across passes becomes the verdict. For the overall evaluation, we average the per-image proportions of concepts assigned to each verdict, giving each image equal weight.

To examine alignment across broader concept groups, we apply agglomerative clustering with cosine distance and average linkage to the parent concepts, each represented by the L2-normalized mean of its phrase embeddings. We assess cluster separation using silhouette scores for \(k=3,\ldots,15\). For \(k\in\{3,5,8,10\}\), we aggregate the existing MedGemma verdicts by mapping each predicted phrase to its parent concept’s cluster, without querying the evaluator again. Within each cluster, verdict percentages are calculated over phrase–image pairs.

Finally, we assess evaluator reliability on 25 concept--report pairs, sampled by MedGemma's original verdict: 8 Aligned, 8 Unaligned, and 9 Uncertain. The three authors independently label these pairs with MedGemma's verdicts hidden, and majority vote defines the reference for measuring evaluator agreement. Three commercial language models also classify the same pairs using both file attachments and pasted text, allowing us to examine sensitivity to input format. This small, stratified audit measures agreement on report interpretation without expert review of the X-ray images.
